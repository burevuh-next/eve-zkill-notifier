# EVE Online zKill Notifier (v3.5) 🚀

Асинхронный Discord-бот на Python для мгновенного отслеживания убийств (killmails) в EVE Online. 
Использует технологию WebSockets для получения данных в реальном времени.

## 🌟 Основные возможности
- **Real-time мониторинг**: получение данных через WebSocket zKillboard (задержка < 1 сек).
- **Умная фильтрация**: отслеживание конкретных корпораций, систем, созвездий или типов кораблей.
- **Обогащение данных**: автоматический сбор полной информации через CCP ESI API.
- **Гибкая настройка**: всё управление через файл `.env`.

## 🛠 Архитектура данных
Бот работает по следующей цепочке:
1. Подписка на каналы через **zKillboard WebSocket**.
2. Получение `killID` и `hash`.
3. Запрос полных данных о жертве и атакующих через **CCP ESI**.
4. Проверка условий в `parser.py`.
5. Отправка форматированного уведомления в **Discord Webhook**.
