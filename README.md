# 🌌 EVE Online zKillboard Discord Bot

Интеллектуальный бот для мониторинга активности в EVE Online через WebSocket zKillboard. Бот отслеживает гибели кораблей в реальном времени и отправляет уведомления в Discord с гибкой фильтрацией и системой приоритетов.

## ✨ Основные функции

* **Мониторинг в реальном времени**: Мгновенные уведомления через WebSocket.
* **Система приоритетов**: Пинг `@everyone` при появлении конкретных кораблей или активности в определенных системах.
* **Динамическая настройка**: Добавление и удаление фильтров (системы, регионы, корпорации, типы кораблей) прямо через Discord-команды без перезагрузки бота.
* **Интеллектуальный парсинг**: Автоматическое определение имен персонажей, корпораций и названий систем через ESI.
* **Фильтрация по стоимости**: Игнорирование мелких киллов (настраиваемый порог ISK).

## 🚀 Быстрый запуск

1.  Создайте файл `.env` на основе примера:
    ```env
    DISCORD_BOT_TOKEN=ваш_токен
    DISCORD_CHANNEL_ID=айди_канала
    MIN_VALUE=100000000
    WATCHED_REGIONS_IDS=10000022,10000002
    PING_SHIP_IDS=670,33328
    ```
2.  Запустите бота:
    ```bash
    python main.py
    ```

## 🛠 Команды бота

| Команда | Описание | Пример |
| :--- | :--- | :--- |
| `!status` | Показать текущие фильтры и настройки | `!status` |
| `!add [тип] [ID]` | Добавить объект для отслеживания | `!add system 30000142` |
| `!remove [тип] [ID]` | Удалить объект из списка | `!remove ship 670` |
| `!check [ID]` | Узнать имя объекта по его ID через ESI | `!check 30000142` |
| `!ping` | Проверить работоспособность бота | `!ping` |

**Доступные типы для команд add/remove:**
`system`, `region`, `ship`, `corp`, `char`, `consts`, `ping_sys`, `ping_ship`.

## ⚙️ Архитектура проекта

* `main.py` — Ядро бота, управление жизненным циклом потоков и конфигурацией.
* `listener.py` — Работа с WebSocket zKillboard, подписка на каналы.
* `processor.py` — Обработка очереди данных и логика уведомлений.
* `parser.py` — Фильтрация киллмейлов и определение типов событий.
* `discord_utils.py` — Логика Discord-бота, команды и форматирование Embed-сообщений.

## ⚠️ Требования
* Python 3.10+
* Библиотеки: `discord.py`, `aiohttp`, `websockets`, `python-dotenv`
